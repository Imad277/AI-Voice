# VoiceOS Architecture

This directory contains architecture documents that have been reviewed and accepted for implementation.

## Source-of-truth hierarchy

1. Accepted ADRs in `/docs/architecture/decisions/`
2. Approved project architecture documents in `/docs/architecture/`
3. Explicit scoped implementation instructions
4. Manus research/specifications in `/docs/research/manus/`

Research recommendations are not architecture decisions until promoted through review and an accepted ADR.
