# Manus Research

This directory contains research, audit, and validation specifications produced by Manus for the VoiceOS project.

## Important status rule

These documents are **research and specification inputs**. They are **not automatically approved architecture decisions**.

Terms such as:

- `PROPOSED`
- `NOT TESTED`
- `PRIMARY CANDIDATE`
- `RECOMMENDED`
- `SHORTLIST`

must not be interpreted as an accepted architecture decision.

Approved architecture decisions belong exclusively in:

`/docs/architecture/decisions/`

If a Manus document conflicts with an accepted ADR, the accepted ADR has precedence.

Claude Code must not implement the complete contents of this directory unless an explicit scoped implementation task authorizes it.

## Directory structure

- `audit/` – first Manus research and market/technology audit, documents 01–12.
- `validation/` – second Manus validation and benchmark specification, documents 01–12.

## Current project state

The validation material currently describes proposed benchmark and decision-gate processes. Practical results remain `NOT TESTED` unless a later approved evidence artifact explicitly states otherwise.
